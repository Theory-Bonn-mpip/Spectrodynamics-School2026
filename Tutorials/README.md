# Tutorials

Hands-on material for **SpectroDynamics 2026**. Each tutorial is self-contained
and lives in its own folder, with its own setup instructions.

| | Tutorial | Topic |
|---|---|---|
| I | [`Tutorial_I`](Tutorial_I) | Quantum dynamics: numerically solving the time-dependent Schrödinger equation for a coupled two-state system driven by a laser field |
| II | [`Tutorial_II`](Tutorial_II) | Vibrational spectroscopy from molecular dynamics: IR, Raman and SFG spectra of water with [i-PI](http://ipi-code.org) and [MACE](https://github.com/ACEsuit/mace) machine-learning models |
| III | [`Tutorial_III`](Tutorial_III) | Electronic spectroscopy from first principles, with [Octopus](https://octopus-code.org) and [DFTB+](https://dftbplus.org) |
